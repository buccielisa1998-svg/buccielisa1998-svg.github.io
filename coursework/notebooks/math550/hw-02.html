Exercise 4.

a) Classification is used when the response variable is categorical, meaning the outcome falls into one of several classes. For example when we have to decide if an email is spam or not based on certain criteria like (content, number of links, sender domain, presence of suspicious words) so we can do a prediction on the next email based on thus data. Or for example on a medical diagnosis based on data.

b) Regression is used when the response variable is quantitative, meaning the outcome is a continuous numerical value. For example the house price prediction based on data like: Size, number of bedrooms, location, age of the house, proximity to schools, or the weather forecasting based on the data of the previous days.

c) Moreover for example of Cluster analysis is used when there is no response variable. We find similarity in the groups and we put it into clusters, so it is an unsupervised learning method. This has application for example in image Compression by grouping similar pixels.

test_point = np.array([0, 0, 0])
